# Lite Slider

Lite Slider is a free, responsive slider block for [ConcreteCMS](https://www.concretecms.org/) by [Xanweb](https://www.xanweb.com/), based on [Glide.js](https://glidejs.com/).

Get it from the [ConcreteCMS marketplace](https://market.concretecms.com/products/lite-slider/76c017cb-d1b3-11ee-b9df-0a97d4ce16b9) or from this repository.

## Features

- Add, delete and drag-and-drop slides; import several images at once.
- A link, title and rich text description for each slide.
- Animation type, effect and speed; autoplay, pause on hover and loop settings.
- Arrows, bullets or both for navigation; touch and drag support.
- Title, box and overlay colors.
- Thumbnail types per device (large desktop, desktop, tablet, phone) and a maximum slide width.
- Look and feel can be adjusted with CSS custom properties (`--xw-lite-slider-*`).

## Requirements

- ConcreteCMS 9.0 or later
- PHP 7.4 or later

## Install

From the ConcreteCMS marketplace, or from this repository:

1. Clone it into your site's `packages` folder:

   ```
   git clone https://github.com/Xanweb/xw_lite_slider.git packages/xw_lite_slider
   ```

   Or download a zip from the [releases page](https://github.com/Xanweb/xw_lite_slider/releases) and extract it into `packages/`.

2. Log in to your site as an administrator.
3. Go to Dashboard, Extend ConcreteCMS, and find Lite Slider in the list of packages awaiting installation.
4. Click Install.

The package adds a Lite Slider block type to the Multimedia set.
